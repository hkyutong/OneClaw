# OneClaw examples

If you are evaluating whether OneClaw is only a product idea or can map to real workflows, start here.

OneClaw is built on OpenClaw, so the strongest public proof comes from the upstream OpenClaw ecosystem and showcase.

> These examples are not claimed as OneClaw-only features. They are evidence of the runtime and workflow model that OneClaw inherits from upstream.

## What these examples mean for OneClaw

- they show that chat-first assistant workflows are real, not just a landing-page claim
- they show that Telegram, browser automation, local skills, and hardware control all fit the same runtime model
- they show why OneClaw can position itself as the easier productized entry point into this ecosystem
